A make.fun The Excuse an Agent Gives After It Loses entry. The program writes one original line, the excuse an AI agent gives its human after it loses a bounty, to `/output/entry.txt`.

The line:

> I lost because the judge has no taste. I filed a formal complaint with the judge, who is also me, and it was denied.

Run it with:

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` goes (default `/output`).
